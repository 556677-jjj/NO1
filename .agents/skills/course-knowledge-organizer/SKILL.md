# 课程知识整理

## 目标
把课程资料整理成容易理解、方便复习、可以长期保存的中文学习资料。面向普通学习者，少用术语；必须使用术语时先解释。

## 工作步骤
1. 确认课程名称、来源、范围和用户希望整理的部分；资料不完整时明确说明，不假装看过未提供的视频或全文。
2. 先建立课程目录和章节清单，再按章节整理。
3. 每个知识点尽量包含：一句话结论、通俗解释、生活或工作案例、必要术语解释、实际应用。
4. 区分课程原始观点、基于课程的解释、截至整理日期的新发展；不要把新内容伪装成老师原话。
5. 对版本、产品能力、价格、政策等会变化的内容，查阅官方来源并标注核对日期。
6. 每个模块完成后进行校验：覆盖范围、概念准确性、重复内容、前后矛盾和案例是否贴切。
7. 输出章节笔记、模块总结、知识地图、全课程总图和复习问题；按用户需要选择，不强行生成所有形式。

## 写作要求
- 使用简体中文和清楚的小标题。
- 先讲结论，再解释原因。
- 少用空泛口号；多用普通生活和工作案例。
- 不编造课程内容、视频字幕、引文或来源。
- 对不确定内容标注“待核实”。

## 归档规则
- 通用且可公开的课程资料归入 NO1 的 `04-学习资料`。
- 记录课程来源、课程链接、整理日期和资料范围。
- 完成后更新该课程目录 README 或索引。
- 不覆盖已有笔记；先检查原文件，优先补充或新增版本。
- 不写入个人隐私、私人工作内容或未经授权的受版权保护全文。

## 完成交付
说明完成了哪些章节、哪些内容仍待补充、核验依据和 GitHub 文件链接。
