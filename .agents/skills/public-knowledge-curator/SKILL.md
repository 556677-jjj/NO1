# 公开知识归档

## 适用范围
只处理适合公开分享的通用知识。私人工作、个人生活、身份信息、公司内部资料和未公开项目不属于本技能范围，应转入 NO2 或先询问。

## 工作步骤
1. 检查 NO1 当前目录结构和相关文件，避免重复建立主题。
2. 判断资料是否有公开授权、是否包含个人信息、内部信息、截图隐私或受版权保护的大段原文。
3. 提炼为原创摘要、步骤、案例和来源列表，不整段复制受版权保护内容。
4. 使用通俗中文，记录来源、作者/机构、发布日期（如有）和核对日期。
5. 放入合适分类，更新 README 或索引。
6. 写入前检查目标文件是否存在；存在则先读取并选择安全的补充方式。
7. 完成后复查链接、文件名、目录导航和公开风险。

## 权限边界
- 公开发布、跨仓库复制、删除文件、改变仓库可见性、覆盖重要原件，必须得到用户明确确认。
- 不从 NO2 读取私人内容后直接复制到 NO1。
- 不保存密码、验证码、API 密钥、私钥和其他秘密。

## 交付
列出新增或修改文件、内容摘要、来源、核验情况和可直接打开的 GitHub 链接。
