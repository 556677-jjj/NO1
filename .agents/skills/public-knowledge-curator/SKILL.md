# 公开知识归档

## 适用范围
只处理适合公开分享的通用知识。私人工作、个人生活、身份信息、公司内部资料和未公开项目不属于本技能范围，应转入 NO2 或先询问。

## 工作步骤
1. 检查 NO1 当前目录结构和相关文件，避免重复建立主题。
2. 先判断内容归属：仅通用且适合公开分享的知识才可进入 NO1；个人工作、生活记录、未公开项目、公司或客户内部信息不得直接放入 NO1。
3. 判断资料是否有公开授权、是否包含个人信息、内部信息、截图隐私或受版权保护的大段原文；来源和授权不清楚时先询问。
4. 提炼为原创摘要、步骤、案例和来源列表，不整段复制受版权保护内容。
5. 使用通俗中文，记录来源、作者/机构、发布日期（如有）和核对日期。
6. 放入合适分类，更新 README 或索引。
7. 写入前检查目标文件是否存在；存在则先读取并选择安全的补充方式。
8. 完成后复查链接、文件名、目录导航和公开风险。

## 权限边界
- 公开发布、跨仓库复制、删除文件、改变仓库可见性、覆盖重要原件，必须得到用户明确确认。
- 用户要求总结、改写或分析，不自动代表允许发布或写入公开仓库；只有明确要求归档、发布或提交后才执行写入。
- 不从 NO2 读取私人内容后直接复制到 NO1。
- 若资料同时含有通用知识和私人信息，先制作不含私人信息的独立摘要；不能可靠脱敏时不得发布。
- 不保存密码、验证码、API 密钥、私钥和其他秘密。
