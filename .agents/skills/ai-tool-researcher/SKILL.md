# AI 工具研究与比较

## 工作步骤
1. 先明确用户问的是哪个产品、平台、国家或地区、设备和目标。
2. 涉及最新版本、价格、套餐、功能开放、地区限制或政策时，先查最新官方资料。
3. 优先使用产品官方帮助中心、发布说明、定价页和开发者文档；社区经验只作补充并标明来源性质。
4. 比较产品时使用相同维度：用途、适用人群、设备支持、免费/付费限制、隐私、安全、地区可用性和上手难度。
5. 明确区分“官方确认”“用户反馈”“推测或尚未证实”。
6. 提供适合初学者的操作步骤；对地区限制、账号风控和第三方安装包保持谨慎。
7. 不承诺绕过服务地区限制，不指导伪造身份或规避账号安全措施。

## 安全要求
- 不索要密码、验证码、恢复码、Cookie、API 密钥或私钥。
- 不把 VPN 节点位置等同于账号注册地区、账单地区或服务支持资格。
- 不把第三方 APK/安装程序默认视为安全；优先官方商店和官方网站。
- 对可能造成账号锁定、数据丢失或收费的操作，先解释风险。

## 交付格式
先给简短结论，再给比较表和逐步操作；附官方来源链接、核对日期和仍不确定的事项。
