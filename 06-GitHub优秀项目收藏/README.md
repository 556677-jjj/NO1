# GitHub 优秀项目收藏

这里专门收藏从 GitHub 发现、经过初步筛选、值得进一步了解或尝试的开源项目和实用程序。

它是跨分类的项目发现区：AI、电脑软件、手机应用、学习工具和个人效率项目都可以收录。原项目始终以 GitHub 作者的仓库为准；本目录保存的是项目索引、评估和个人使用记录。

## 如何使用

1. 发现项目后，把 GitHub 项目链接发给 ChatGPT，并说明你想解决的问题。
2. 先评估项目是否符合需求，再决定是否收藏；不要只凭 Star 数量判断。
3. 将确认值得收藏的项目复制一份「项目收藏模板」填写。
4. 安装或运行前，先检查来源、许可证、维护状态、依赖和安全风险。
5. 尝试后补充实际使用体验、问题和是否推荐。

## 项目分类

- AI 与自动化
- Windows / 电脑软件
- Android / 手机应用
- 学习与知识管理
- 办公与个人效率
- 其他有趣项目

## 筛选与安全原则

- 优先记录原始作者仓库和官方发布页面，不使用来历不明的转载下载地址。
- 查看许可证（License）；没有明确许可证时，不默认可以自由复制、修改或商用。
- 查看最近更新时间、Release、Issue 和维护者响应情况。
- 检查安装步骤、运行权限、外部依赖、网络访问和是否要求管理员权限。
- 不运行来源不明的脚本，不粘贴未知命令；涉及账号、密钥、个人文件或系统设置时先确认。
- 对安全性无法确认的项目，标记「待进一步检查」，不要标记为安全。
- Star、下载量和社区热度只能作为参考，不能替代代码与来源检查。

## 收藏状态

- 待评估：刚发现，尚未完成检查
- 值得尝试：初步符合需求，准备测试
- 已试用：已经安装或运行并记录体验
- 正在使用：当前仍在使用
- 暂不推荐：存在明显限制、风险或不符合需求
