## 一、这一节要解决什么问题？

数据是 AI 系统的重要基础，但“数据”究竟是什么？怎样的数据对一个 AI 项目有用？又该如何收集、整理和判断数据质量？

本节借助房屋定价、图片识别和电商网站等例子说明：**数据不是为了囤积而囤积；只有围绕具体业务问题收集、定义和使用的数据，才可能产生价值。**

## 二、核心知识点

### 1. 数据集可以是一张表格

数据集（Dataset）可以先简单理解为一组有组织的样本。比如房屋定价：

| 房屋面积 | 房屋价格 |
|---:|---:|
| 80 平方米 | 200 万 |
| 100 平方米 | 260 万 |
| 120 平方米 | 310 万 |

如果希望 AI 帮助估算房价，可以把房屋面积作为输入 A，把价格作为输出 B，让模型从历史样本中学习两者之间的关系。

如果再加入卧室数量、地段等信息，输入 A 就不止一个字段。**哪些信息作为输入、要预测什么作为输出，取决于具体业务目标。**

同一份数据也可以服务于不同问题。例如：
- 已知房屋面积，预测价格；
- 已知预算，估计能买到多大面积的房屋。

两者使用的数据可能相似，但 A 和 B 的定义不同。

### 2. 数据是围绕业务问题定义的

数据并不是天然就带着“应该怎样使用”的说明。业务人员需要先明确：
- 想解决什么问题？
- 哪些信息在预测时能够获得？
- 希望模型给出什么结果？
- 怎样判断结果是否正确、有用？

数据往往具有业务特定性。房地产企业关注房屋面积、地段和成交价格；电商企业可能关注商品、价格、用户浏览和购买行为。不能脱离场景，笼统地说某一批数据一定有价值。

### 3. 数据也可以是图片、音频和文本

课程用识别猫的图片作为例子：
- 输入 A：一张图片；
- 输出 B：图片中是否有猫；
- 训练样本：图片以及人工确认的标签。

人工标注（Manual Labeling）是获得带答案样本的一种方法。人逐张检查图片并标记“有猫”或“没有猫”，形成可供监督学习使用的数据集。真实项目通常需要远多于几个示例的样本。

课程还提到另一类数据获取方式：观察用户或其他行为。例如电商网站可以记录用户看到某个商品或价格后是否购买。购买与否可以成为行为数据的一部分，但解释这些数据时仍要注意情境，不能简单把一次行为当成用户永远不变的偏好。

### 4. 结构化数据与非结构化数据

| 类型 | 含义 | 常见例子 |
|---|---|---|
| 结构化数据（Structured Data） | 以固定字段组织，适合放入表格或数据库 | 房屋面积、价格、订单日期、库存数量 |
| 非结构化数据（Unstructured Data） | 不容易直接整理成固定行列字段的内容 | 图片、录音、视频、自然语言文本 |

不同数据形式往往需要不同的处理方法。例如，表格数据和图片数据的特征表示方式不同。但两者都可能用于机器学习任务。

### 5. 不要为了“将来可能有用”而盲目囤积数据

本节提醒企业，不要先花几年时间收集大量数据、建设庞大的 IT 系统，然后才让 AI 团队查看数据。

更有效的做法通常是：**尽早让懂 AI 和业务的人一起检查已有数据，并根据具体应用需求反馈还需要采集什么。**

例如，工厂希望预测设备何时可能故障。AI 团队检查现有设备记录后，可能发现每十分钟采集一次的数据太稀疏，若能每分钟记录一次关键指标，预测维护可能更有帮助。

这说明数据采集频率、字段和质量应由目标任务反向决定。不要为了“数据越多越好”而投入资源。

### 6. 数据很容易出错：Garbage In, Garbage Out

“Garbage in, garbage out”（垃圾进，垃圾出）强调：如果输入数据有问题，模型可能学到错误规律。

常见数据问题包括：
- **错误数据或错误标签**：例如房屋价格字段录入了明显不合理的数字；
- **缺失值**：某些房屋没有填写卧室数量或价格；
- **不一致**：同一字段的单位、格式或记录规则不同；
- **代表性不足**：样本没有覆盖真实使用中会遇到的人群、地区或情况；
- **采集方式不合适**：数据频率或字段无法支持目标应用。

AI 团队需要检查数据、修正错误、处理缺失值，并判断数据是否足以支持目标任务。清理数据不是可有可无的杂事，而是项目的重要工作。

## 三、把这一节用在实际生活中

假设想让 AI 帮你把电脑文件自动归类：

- **业务目标**：把文件分到“AI 工具、电脑软件、手机应用、学习资料、个人生活”等类别。
- **可能的输入 A**：文件名、扩展名、文件内容摘要、来源、创建时间。
- **输出 B**：建议归属的文件夹类别。
- **训练样本**：以前由人确认过分类的文件及其正确类别。
- **需要检查的数据问题**：文件名是否含糊、同一类文件是否有不同叫法、旧分类是否一致、是否存在敏感文件。

这个例子说明，数据应该服务于清楚的分类目标；不能只把所有文件信息收集起来，就期待系统自动变聪明。实际整理时还应保护隐私，并让重要分类结果经过人工确认。

## 四、普通学习者应该记住的五件事

1. **先有问题，再定义数据。** 不要先问“我能收集什么”，而要先问“我想解决什么问题”。
2. **输入和输出由目标决定。** 同一批数据可能用于不同任务，A 和 B 的定义也会改变。
3. **数据不只有表格。** 图片、音频、视频和文本都可能成为机器学习数据。
4. **质量比盲目堆数量更重要。** 错误、缺失和偏差会影响模型结果。
5. **尽早让 AI 团队参与数据规划。** 他们可以帮助判断哪些数据值得采集、采集多频繁，以及现有数据能否支持目标。

## 五、关键术语卡片

| 英文术语 | 中文 | 简单解释 |
|---|---|---|
| Data | 数据 | 对事物、事件或行为的记录 |
| Dataset | 数据集 | 为某个分析或建模任务组织起来的一组样本 |
| Input (A) | 输入 | 提供给模型的信息 |
| Output (B) | 输出 | 模型需要预测或给出的目标结果 |
| Label | 标签 | 样本对应的正确类别或答案 |
| Manual Labeling | 人工标注 | 由人检查样本并添加标签 |
| Structured Data | 结构化数据 | 按固定字段组织的数据 |
| Unstructured Data | 非结构化数据 | 图片、音频、文本等不易直接放进固定表格的数据 |
| Missing Value | 缺失值 | 某个字段没有记录或记录为空 |
| Data Quality | 数据质量 | 数据的准确性、完整性、一致性和适用性 |

## 六、复习问题

1. 什么是数据集？房屋定价例子中的输入 A 和输出 B 分别是什么？
2. 为什么同一份房屋数据可以用于不同的预测任务？
3. 图片识别任务中，人工标注起什么作用？
4. 结构化数据和非结构化数据分别有哪些例子？
5. 为什么不建议企业先盲目收集几年数据，再考虑 AI 应用？
6. “垃圾进，垃圾出”是什么意思？请举出两种可能导致模型出错的数据问题。
7. 如果要用 AI 帮你整理电脑文件，你会选择哪些输入字段，怎样定义输出类别？

## 七、学习总结

本节最重要的结论：

**数据的价值取决于它是否能帮助解决一个明确的问题。**

一个可靠的数据项目，不是简单追求数据量，而是要先定义业务目标和输入输出，再选择合适的数据来源、采集方式与质量检查方法。数据可能来自表格，也可能来自图片、声音、文本和行为记录；无论形式如何，都要检查错误、缺失和代表性。
