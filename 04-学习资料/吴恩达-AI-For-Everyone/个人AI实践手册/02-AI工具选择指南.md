# 第二章：AI 工具选择指南

> 一句话目标：不要为了追赶新工具而学工具；先看自己要完成什么，再挑最合适的帮手。  
> 面向读者：没有编程基础、希望把 AI 用在学习、工作和生活中的普通用户。  
> 内容核对日期：2026-11-07

## 一、先记住：没有一个 AI 能包办所有事情

可以把 AI 工具想成一支不同岗位的小团队：

- 有的像**顾问**：帮你分析问题、解释知识、制定计划。
- 有的像**资料研究员**：上网查资料、比较不同来源、整理报告。
- 有的像**文件助理**：阅读 PDF、表格、图片，提取和整理内容。
- 有的像**电脑操作员**：在你授权的范围内处理文件、运行命令、操作软件。
- 有的像**长期资料管理员**：把成果按目录保存，方便以后查找和继续修改。

你不需要每一种都用，也不需要同时订阅很多服务。先把常用的一两个工具用熟，再根据任务补充其他工具。

**生活例子：** 你想买一台新电脑。第一步不是问“哪个 AI 最强”，而是先明确预算、用途、常用软件和最在意的条件。接着让 AI 帮你列需求、查当前型号、比较参数，最后你自己核对价格、保修和购买渠道。每一步需要的能力不同。

## 二、选择工具前，先问自己五个问题

1. **我要得到什么结果？** 是一段说明、一份报告、一张表格、一张图片，还是电脑里真正完成的操作？
2. **资料在哪里？** 在网页、PDF、手机截图、Excel、YouTube 视频，还是 GitHub 仓库？
3. **需要最新信息吗？** 如果涉及今天的价格、软件版本、政策或新闻，就必须查当前来源，不能只靠 AI 的旧知识。
4. **需要它动手做吗？** 只要建议，还是需要它创建文件、修改代码、整理文件夹或操作软件？
5. **出错的代价有多大？** 普通文案可以先看草稿；涉及钱、账号、安全、法律或重要文件，就要更严格地核实和人工确认。

把这五个问题说清楚，通常就能选对工具的大方向。

## 三、常见 AI 工具，各自适合做什么？

下面不是绝对排名，而是按常见用途划分。不同版本、账号套餐、地区和设备可能开放不同功能；实际使用时以你当前界面和官方说明为准。

### 1. ChatGPT：适合当日常总助手

可以把 ChatGPT 理解为一个能讨论问题、解释知识、整理材料、协助研究和制作成果的综合助手。

常见用途：
- 把复杂知识讲简单，例如解释机器学习、电脑设置或软件功能。
- 整理学习笔记、写计划、修改说明文字。
- 阅读你提供的文件，归纳重点、提取信息。
- 在支持的情况下分析表格、制作图表。
- 对需要最新信息的问题进行联网查找，并整理来源。
- 把一个大任务拆成步骤，逐步推进。

**贴近生活的例子：** 你在手机上看到一个不认识的设置页面，可以发截图并问：“请用中文告诉我这个页面每个选项有什么作用，哪些不要随便改，按步骤指导我。”这类解释和陪伴式操作指导，就是日常助手的典型用法。

注意：文件上传、数据分析、联网研究和其他高级功能会受账号、套餐、地区、使用额度及当前产品开放情况影响。官方功能说明：[ChatGPT 能力概览](https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview)、[ChatGPT 数据分析](https://help.openai.com/en/articles/8437071)。

### 2. ChatGPT Work：适合较长的多步骤任务和完整成果

如果普通聊天更像“随时提问的助手”，ChatGPT Work 可以理解为“接手一项较完整工作的工作台”。它更适合需要连续几个步骤、查阅资料、分析内容并整理成最终成果的任务。

常见用途：
- 研究一个主题，整理多份资料并形成报告。
- 围绕一组文件持续分析、修改和完善成果。
- 把复杂任务拆成多个步骤，并在过程中检查进度。
- 在当前账号和工作环境支持的范围内，使用已连接的工具完成工作。

**生活例子：** 你想把一门课程做成系统学习资料，可以先让 Work 帮你核对资料清单、设计章节结构、整理内容，再检查是否遗漏。涉及真实文件写入、删除或对外发送时，仍要确认权限和操作结果。

Work 与 Codex 不要混为一谈：Work 更偏向研究、分析和交付各种工作成果；Codex 更偏向软件开发、代码和技术项目。具体功能、使用额度和入口会因账号、套餐、设备及开放情况变化。

官方说明：[ChatGPT Work 与 Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)。

### 3. Gemini：适合结合 Google 生态和处理多种资料

如果你的资料主要在 Google 的服务中，或者要处理文档、图片、视频等多种资料，可以了解 Gemini 的相关能力。

常见用途（以账号当前开放的功能为准）：
- 阅读上传的文档、表格、图片和部分视频资料。
- 在支持的情况下结合 Google 搜索做深入研究。
- 在连接和授权后，使用符合条件的 Google 服务资料。
- 帮助理解长文档、归纳内容或根据表格制作图表。

**贴近生活的例子：** 你有一份很长的产品说明书 PDF，可以上传后问：“请用普通人能听懂的话解释安装步骤，列出最容易做错的三件事，并告诉我哪些内容需要回到原说明书确认。”

官方说明：[Gemini 文件上传与分析](https://support.google.com/gemini/answer/14903178)、[Gemini 深入研究](https://support.google.com/gemini/answer/15719111)。

### 4. Claude：适合长文阅读、写作和整理复杂材料

Claude 可以作为另一位写作和分析助手。它也提供文件处理、项目资料组织、联网研究、连接工具等能力，具体开放情况会因版本和账号而不同。

常见用途：
- 阅读较长的文章、报告或多份材料。
- 对已有文字进行改写、润色和结构调整。
- 整理一份较完整的方案、说明或文档。
- 在支持的情况下制作可继续编辑的文件或交互式内容。

**贴近工作例子：** 你有几份会议记录，希望整理成一份工作方案。可以要求它先找出共同问题，再区分已经决定的事项和仍待讨论的事项，最后形成一份有标题、责任人和下一步安排的草稿。

官方能力说明：[Claude 产品概览](https://claude.com/product/overview)。

### 5. Codex：适合让 AI 参与电脑和软件项目的实际执行

Codex 与普通聊天助手的重点不同。它更偏向执行型工作，尤其适合软件开发、代码检查、项目文件处理和在授权环境中完成多步骤任务。

常见用途：
- 检查一个项目里有哪些文件、它们之间有什么关系。
- 修改代码、排查错误、运行测试。
- 按要求创建或整理项目文件。
- 在支持的环境和权限下，协助操作电脑上的应用或命令行。

**贴近生活例子：** 你不需要自己学习编程才能提出一个简单需求，例如：“请检查这个文件夹里的资料，按主题整理成目录。先列出准备移动的文件和新位置，等我确认后再执行。不要删除任何文件。”如果当前 Codex 环境能访问该文件夹，它就可以尝试按步骤完成；如果没有文件访问权限，就需要先配置正确的工作目录或授权。

重要提醒：Codex 可能会执行命令或修改文件。开始前要确认它访问的是正确文件夹；重要文件先备份；删除、覆盖、发布或提交等有影响的操作要先审查。官方介绍：[Codex 应用介绍](https://openai.com/index/introducing-the-codex-app/)；[Codex 使用说明](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)。

### 6. GitHub：它不是聊天 AI，而是保存成果的地方

GitHub 本身不是用来回答日常问题的聊天机器人。它更像一个有历史记录的线上资料柜，尤其适合保存文档、项目文件和修改记录。

可以把它理解为：
- ChatGPT 等工具负责讨论和整理。
- Codex 等执行工具负责按要求创建、修改和检查文件。
- GitHub 负责长期保存成果、记录每次修改，并让以后能找到旧版本。

**贴近生活例子：** 你让 AI 整理了一份手机软件使用指南。不要只让它留在聊天记录里，可以把它保存到 GitHub 的“手机应用”分类。以后软件更新了，再修改这份指南，同时保留修改记录。

## 四、快速选择表：遇到不同任务，先从这里判断

| 你要做的事情 | 优先考虑 | 为什么 |
|---|---|---|
| 解释一个概念、讨论想法 | ChatGPT 或 Gemini、Claude | 适合问答、解释和讨论 |
| 写一封邮件、整理一份计划 | ChatGPT 或 Claude | 适合起草、修改和组织文字 |
| 查最新政策、价格、软件版本 | 带联网研究能力的助手 | 需要查当前网页和来源 |
| 阅读 PDF、表格、截图 | 支持对应文件类型的助手 | 可以直接围绕你的资料提问 |
| 深入研究一个复杂主题、整理成完整成果 | ChatGPT Work 或 Deep Research 等功能 | 适合多步骤研究和交付；具体入口以账号当前界面为准 |
| 修改代码、运行测试 | Codex 等编程执行工具 | 更偏向软件开发和技术项目，可在授权范围内执行任务 |
| 保存长期知识和项目资料 | GitHub 或其他文件库 | 方便分类、追踪修改和复用 |
| 制作图片 | 图像生成工具 | 文字助手未必能直接生成你需要的图片 |

记住：表格只是起点，不是规定。一个工具也可能同时完成多种任务。选工具时看它当前是否有你需要的功能，而不是只看品牌名称。

## 五、最实用的办法：让几个工具分工合作

不要把所有事情都塞给一个 AI。复杂任务可以像安排工作一样分工。

### 案例 A：把 YouTube 学习视频整理成知识库

1. **明确学习目标**：先确定视频主题、课程范围和希望得到的成果。
2. **取得可靠资料**：优先使用课程官方页面、视频字幕或可核对的文字资料。
3. **让 ChatGPT 整理**：提炼知识点，用通俗中文解释，加入生活案例和复习题。
4. **核对重要内容**：检查课程原意、术语和现代补充有没有混在一起。
5. **保存到 GitHub**：按课程和章节分类，更新目录并检查链接。

这套流程的重点不是某一个工具，而是每一步都有明确责任。

### 案例 B：整理电脑软件使用说明

1. 把软件名称、版本和遇到的问题告诉 ChatGPT。
2. 如果需要最新步骤，让助手查软件官方帮助页面。
3. 提供报错截图，让 AI 解释页面上每个选项。
4. 如果涉及电脑文件操作，再考虑用 Codex 或其他有电脑操作能力的工具。
5. 操作前备份；操作后检查软件能否正常运行。
6. 把最终确认有效的步骤保存到“电脑软件”分类。

### 案例 C：比较几个 AI 工具

不要只问“哪个 AI 最强”。改成给它们同一份任务，例如：“请把这份说明整理成一页中文操作指南，面向完全没有基础的人，必须列出步骤和风险。”

比较时看五件事：
- 是否理解了要求？
- 是否有明显错误？
- 是否讲得清楚？
- 是否真的完成了要求的格式？
- 是否能提供来源或让你检查依据？

这样比较出来的结果，才和你的真实用途有关。

## 六、学会判断：什么时候需要换工具？

出现下面情况时，可以考虑换工具或换方法：

- **它没有你需要的资料**：先提供文件、截图或可靠链接；仍无法读取，再换支持该资料类型的工具。
- **它无法查最新信息**：使用联网搜索或官方来源，不要让它凭记忆猜。
- **它只能告诉你怎么做，不能替你操作**：如果任务确实需要操作电脑，考虑有相应权限的执行工具。
- **它反复答非所问**：把任务缩小，给出示例和验收标准；必要时换一个助手交叉检查。
- **它做得很快但错误很多**：降低任务难度，要求列出依据、假设和不确定之处，并人工核对。

换工具不一定能解决问题。有时真正的问题是要求太模糊、资料不完整，或者任务本身不适合自动完成。

## 七、给 AI 安排任务时，可以直接套用这段话

下面这段可以复制后使用。把方括号里的内容换成自己的任务：

> 我想完成的事情是：[写清楚目标]。  
>   
> 我的基础：[例如：没有编程基础，不熟悉这个软件]。  
>   
> 我现在有的资料：[例如：一份 PDF、几张截图、一个网页链接]。  
>   
> 请你先判断这件事适合用什么方式完成。如果你能直接处理，请先说明准备怎么做；如果需要我提供资料或授权，请明确告诉我。  
>   
> 请用通俗易懂的中文回答，少用专业术语，多举实际例子。  
>   
> 完成标准是：[例如：得到一份能照着操作的步骤说明]。  
>   
> 请标出你不确定的地方，不要编造信息。涉及删除、覆盖、付款、发布或账号安全的操作，先停下来让我确认。

这段话的价值在于：你不必一开始就知道该选哪个 AI。先把目标和条件讲清楚，让助手帮助你判断。

## 八、普通用户最容易踩的六个坑

1. **追着新工具跑**：今天装一个，明天换一个，最后没有一个真正用熟。先选一两个常用工具。
2. **只看回答是否流畅**：表达漂亮不代表事实正确。重要内容要核对来源。
3. **把聊天当成永久资料库**：重要成果要另存为文件，放到有分类的地方。
4. **一次交代太多模糊要求**：把大任务拆成几个阶段，每阶段都有明确结果。
5. **让 AI 自己决定所有操作**：涉及文件删除、账号、付款和发布时，必须保留人工确认。
6. **忽视地区和账号限制**：某项功能在官方介绍中存在，不代表每个国家、账号、套餐和设备都能使用。先以自己的实际界面为准，不要为了一个功能随意交出账号或验证码。

## 九、本章动手练习：给自己建立一张 AI 工具分工表

请选三个你近期真的想完成的任务，例如：
- 整理一门课程的视频知识点；
- 解决电脑软件的一个问题；
- 把一份资料保存到 GitHub。

每个任务写下：
1. 最终想得到什么？
2. 需要用到什么资料？
3. 只需要 AI 给建议，还是需要它实际操作？
4. 哪个工具最适合先尝试？
5. 完成后怎样检查结果？

不必追求一次选对。先试用，再根据结果调整。

## 十、本章小结

- 选 AI 工具，先看任务，不要先看品牌。
- ChatGPT、Gemini、Claude 等可承担问答、研究、写作和资料分析等工作，但各自功能和可用范围会变化。
- Codex 等执行型工具更适合在授权环境中处理项目文件、代码和电脑任务。
- GitHub 负责长期保存和管理成果，不是聊天助手。
- 复杂任务要分工、分步骤，并设定完成标准。
- 重要信息必须核实；重要操作必须保留人工确认。

**最重要的一句话：先想清楚要完成什么，再选择工具；工具可以更换，解决问题的方法要留下来。**
