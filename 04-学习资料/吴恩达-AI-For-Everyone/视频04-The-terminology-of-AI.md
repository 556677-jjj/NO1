# 视频 04：The terminology of AI（AI 术语）

> 模块：Week 1 — What is AI?（什么是 AI？）  
> 课程：AI For Everyone  
> 主讲：Andrew Ng（吴恩达）  
> 本节时长：约 9–10 分钟（不同课程版本显示略有差异）

## 一、本节要解决的问题

AI 领域经常同时出现人工智能（AI）、机器学习（Machine Learning）、数据科学（Data Science）、神经网络（Neural Networks）和深度学习（Deep Learning）等词。本节的目标不是让初学者记住一堆名词，而是建立它们之间的大致关系，能够在讨论工作或业务问题时正确使用这些概念。

## 二、先用房价案例理解机器学习

假设要开发一个房价估算应用。手头的数据包括：

- 房屋面积；
- 卧室数量；
- 卫生间数量；
- 是否刚刚翻新；
- 房屋成交价格。

如果把前面几项作为输入 A，把房价作为输出 B，系统就可以学习从房屋特征到价格的对应关系。训练完成后，用户输入一套房屋的特征，软件自动给出估价。

这就是本节用来说明机器学习的典型方式：**从输入 A 学习到输出 B 的映射关系**。

### 机器学习项目通常交付什么？

通常会形成一个可以持续运行的软件系统：新数据进入系统，模型自动产生预测或分类结果。例如房价估算、广告点击预测等。

## 三、机器学习与数据科学有什么不同？

吴恩达用同一份房屋数据说明两类项目的区别。

| 对比 | 机器学习项目 | 数据科学项目 |
|---|---|---|
| 主要目的 | 让系统自动预测或分类 | 从数据中发现规律、形成洞见 |
| 常见产出 | 持续运行的软件/模型 | 分析结论、报告、演示文稿或建议 |
| 房屋案例 | 输入面积、卧室数等，自动估算价格 | 分析卧室数量或翻新情况与房价的关系 |
| 结果如何使用 | 系统自动为大量新样本提供结果 | 人根据分析结果作出业务决策 |

例如，分析发现：在面积相近的房屋中，三居室的价格可能高于两居室；翻新房屋可能存在价格溢价。这样的结论可以帮助企业决定建造哪种户型，或是否值得投资翻新。这是数据科学的典型价值。

**重要提醒：** 机器学习与数据科学在现实行业中的边界并不总是清晰，术语也没有被所有人完全一致地使用。这里是帮助初学者理解的常见区分，不是绝对的行业定律。

## 四、机器学习的经典定义

本节引用了机器学习先驱 Arthur Samuel 的经典表述：机器学习是让计算机在没有被明确逐条编程的情况下获得学习能力的研究领域。

通俗理解：

- 传统程序：人把规则写出来，计算机按规则执行。
- 机器学习：人提供样本和学习方法，计算机从样本中调整模型，再对新样本给出结果。

机器学习并不意味着计算机像人一样理解世界，而是通过数据学习可用于任务的统计规律。

## 五、什么是神经网络和深度学习？

继续使用房价估算例子：把房屋面积、卧室数、卫生间数、是否翻新等输入交给一个模型，模型计算后输出估算价格。这个模型可以是人工神经网络（Artificial Neural Network）。

### 神经网络的初学者理解

- 神经网络是一种软件模型，由相互连接的计算单元组成。
- 这些计算单元及其连接共同构成数学计算过程。
- 模型通过训练调整内部参数，从而学习输入与输出之间的关系。
- 神经网络能够有效处理复杂的输入输出映射任务。

### 深度学习与神经网络

本节指出，在当下常见的行业用法中，“神经网络”和“深度学习”经常被近似地放在一起讨论。深度学习通常指使用多层神经网络的一类机器学习方法。

不要误解为人工神经网络就是人脑的复制品。它的早期灵感与生物神经系统有关，但实际工作细节与人脑神经元活动有很大区别。吴恩达特别提醒，不要把这种松散的灵感关系理解成两者在机制上相同。

## 六、这些概念之间是什么关系？

可以先建立下面这张简化的“概念地图”：

```
人工智能（AI）
├── 机器学习（Machine Learning）
│   ├── 深度学习（Deep Learning）
│   │   └── 多层神经网络是其重要技术基础
│   └── 其他机器学习方法
└── 其他 AI 方法
    ├── 规划（Planning）
    ├── 知识图谱（Knowledge Graph）
    └── 其他方法

数据科学（Data Science）
└── 与 AI、机器学习、深度学习有交叉，
    也会使用统计、分析和其他数据工具
```

这是一张帮助理解的简化图，不是严格的数学集合定义。

本节的关键关系：

1. **AI 是范围更大的领域。** 它包含多种让计算机表现出智能行为的方法。
2. **机器学习是 AI 的重要组成部分。** 但 AI 并不等于机器学习，AI 还有其他技术路线。
3. **深度学习是机器学习中的重要方法。** 神经网络是深度学习的核心模型结构之一，但机器学习并不只有深度学习。
4. **数据科学与上述领域交叉。** 数据科学会使用机器学习等工具，也会使用统计分析、数据处理和其他方法来支持业务决策。
5. **数据科学与 AI 的边界存在不同说法。** 不必死记某一种维恩图；理解各自解决的问题和交付成果更重要。

本节还提到无监督学习、强化学习、图模型、规划和知识图谱等其他术语。初学阶段不必立即深入每一个名词，先理解它们是 AI 工具箱中的不同方法即可。

## 七、用在线广告再对比一次

- **机器学习：** 系统根据用户和广告的相关信息，预测用户是否可能点击某条广告。它持续运行并自动给出预测。
- **数据科学：** 分析广告业务数据，发现某个行业的广告客户较少，进而建议销售团队增加对该行业的拓展。

两者可能在同一家企业同时存在，而且都能创造价值：机器学习帮助系统自动作出预测，数据科学帮助团队发现问题并作出经营决策。

## 八、把本节知识用到日常工作

以个人资料库为例：

- 如果希望系统读入文件信息后，自动预测它属于“AI 工具、电脑软件、手机应用、学习资料、个人生活”中的哪一类，这更接近机器学习式的分类任务。
- 如果希望统计资料库中哪些主题增长最快、哪些类别经常被查阅，并据此调整目录，这更接近数据分析/数据科学任务。
- 如果希望用一个 AI 助手理解问题、检索资料并协助完成复杂工作，则可能需要多种 AI 方法和软件组件协同，而不是只靠一个机器学习模型。

实际应用时应先明确目标、输入、输出和评价标准。分类结果也应允许人工复核，尤其是涉及个人隐私或重要文件时。

## 九、术语卡片

| 英文 | 中文 | 一句话理解 |
|---|---|---|
| Artificial Intelligence (AI) | 人工智能 | 让计算机执行智能任务的广泛技术领域 |
| Machine Learning (ML) | 机器学习 | 通过数据学习规律并用于预测或决策 |
| Data Science | 数据科学 | 从数据中提取知识、洞见并支持决策 |
| Neural Network | 神经网络 | 由相互连接的计算单元组成的模型 |
| Artificial Neural Network (ANN) | 人工神经网络 | 以软件实现的神经网络模型 |
| Deep Learning (DL) | 深度学习 | 使用多层神经网络的机器学习方法 |
| Supervised Learning | 监督学习 | 使用带有目标答案的样本学习输入到输出的映射 |
| Input / Output | 输入 / 输出 | 模型接收的信息与产生的结果 |
| Unsupervised Learning | 无监督学习 | 从没有明确目标标签的数据中寻找结构或规律 |
| Reinforcement Learning | 强化学习 | 通过行动、反馈和奖励信号学习策略 |
| Knowledge Graph | 知识图谱 | 用实体及其关系组织知识的数据结构 |

## 十、复习题

1. 用一句话解释 AI、机器学习和深度学习之间的关系。
2. 如果系统持续接收房屋特征并自动估算价格，这属于机器学习项目还是数据科学项目？为什么？
3. 如果分析师从房屋数据中发现翻新房屋存在价格差异，并向管理者提出投资建议，这属于哪类项目？
4. 为什么不能说人工神经网络就是人脑的数字复制品？
5. 数据科学与 AI 的边界为什么不适合用一张固定的维恩图绝对化？

### 参考答案提示

1. AI 是大领域；机器学习是其中一类方法；深度学习是机器学习的重要分支。
2. 更接近机器学习项目，因为交付的是可持续运行、自动输出估价的软件系统。
3. 更接近数据科学项目，因为核心产出是数据洞见和业务建议。
4. 神经网络只受到生物神经系统的松散启发，实际计算机制与人脑有很大差异。
5. 行业用法并不完全一致，数据科学会横跨统计、机器学习和业务分析等领域。

## 十一、本节最重要的五句话

1. AI 是工具和方法的总称，不是单一技术。
2. 机器学习项目常常交付一个能自动运行的预测或分类系统。
3. 数据科学项目常常交付洞见、分析结论和决策建议。
4. 深度学习是机器学习的重要分支，神经网络是其核心技术基础之一。
5. 学习术语时，与其死记概念边界，不如先弄清楚它要解决什么问题、输入是什么、输出是什么。
