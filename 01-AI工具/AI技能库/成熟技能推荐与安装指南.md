# 成熟 AI 技能推荐与安装指南

核对日期：2026-11-07

本清单优先选择 OpenAI 官方维护的 Codex 技能。它们不是必须全部安装；按实际任务逐项添加即可。

## 一、优先推荐

| 技能名称 | 来源 | 主要用途 | 推荐程度 |
|---|---|---|---|
| `openai-docs` | OpenAI 官方技能库 | 查询 OpenAI、ChatGPT、Codex 和 API 的官方说明 | 高 |
| `pdf` | OpenAI 官方技能库 | 阅读、制作和检查 PDF 文件 | 高 |
| `security-best-practices` | OpenAI 官方技能库 | 在受支持的编程项目中检查安全做法 | 中；有代码任务时使用 |
| `jupyter-notebook` | OpenAI 官方技能库 | 创建和整理 Jupyter 学习笔记、数据实验 | 中；做数据学习时使用 |
| `gh-fix-ci` | OpenAI 官方技能库 | 排查 GitHub Actions 自动检查失败 | 低；有相关开发项目时再安装 |
| `define-goal` | OpenAI 官方技能库 | 把模糊目标整理为可检查的目标 | 可选 |

官方目录：[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated)

## 二、适合当前阶段的安装顺序

建议先安装前三个中的前两个：

1. `openai-docs`：你经常需要了解 ChatGPT、Codex 和 AI 工具的新功能。
2. `pdf`：以后整理课程资料、说明书和报告时会有帮助。
3. `security-best-practices`：当 Codex 开始修改代码或制作小工具时再安装。
4. `jupyter-notebook`：开始做数据分析或可运行的学习实验时再安装。
5. `gh-fix-ci`：以后使用 GitHub Actions 并遇到失败时再安装。

## 三、在 Codex 中安装

在 Codex 对话中逐条输入：

```text
$skill-installer openai-docs
$skill-installer pdf
$skill-installer security-best-practices
$skill-installer jupyter-notebook
```

如要安装其他官方目录技能，可把名称交给 `$skill-installer`。安装后若没有出现，重新打开 Codex。

注意：这是安装到 Codex 本机技能目录的方式，与把本仓库中的自制技能提交到 GitHub 是两件不同的事。

## 四、成熟技能来源与安全检查

优先级建议：

1. OpenAI、Anthropic、Google、GitHub 等官方组织维护的仓库。
2. 有明确维护者、许可证、更新记录和使用说明的成熟开源项目。
3. 个人作者的技能：先审查再考虑使用。

安装前至少检查：

- `SKILL.md` 是否清楚说明触发条件和工作范围。
- 是否包含 `scripts/`、安装命令、外部下载或自动执行行为。
- 是否要求提供密码、API 密钥、浏览器 Cookie 或其他秘密。
- 是否会向外部服务器上传文件或个人数据。
- 许可证是否允许使用和修改。

不要直接运行来源不明的脚本；不要把密码、验证码、API 密钥、私钥交给技能。技能内容本身也可能有错误或恶意指令，不能因为它叫“技能”就默认安全。

## 五、适用范围说明

- OpenAI 官方技能目录中的某项技能，不代表 ChatGPT Free 一定能在 ChatGPT 内置技能选择器中安装或调用。
- Codex 的仓库级技能通常放在项目的 `.agents/skills/` 目录；用户级安装则由安装器放入 Codex 的个人技能目录。
- 本仓库的自制技能主要面向 Codex 在打开 NO1 仓库时使用。ChatGPT 可以阅读这些说明并遵循流程，但这不等同于已在 ChatGPT 账号中安装。
- 官方技能的内容、目录和安装方式可能变化，实际安装前应查看其当前说明。
