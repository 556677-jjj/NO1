# 个人 AI 技能库｜NO1 公共部分

这里保存适合公开分享、可重复使用的 AI 技能说明、成熟技能推荐和安装教程。

## 这套技能库怎么分工

- **NO1（公开）**：通用学习、AI 工具研究、电脑与手机使用、公开知识整理、通用 GitHub 维护方法。
- **NO2（私有）**：个人工作日志、周总结、私人项目、个人生活安排等专属流程。
- **Codex**：在打开相应仓库时读取仓库内 `.agents/skills/` 下的技能。
- **ChatGPT**：可以参考技能说明开展分析和整理；是否能直接从技能选择器调用，取决于账号和当前产品入口。

## NO1 已建立的专属技能

| 技能 | 用途 |
|---|---|
| `course-knowledge-organizer` | 整理课程、视频、章节笔记和知识地图 |
| `ai-tool-researcher` | 调查 AI 工具、版本、价格、地区和使用限制 |
| `windows-android-helper` | 处理 Windows 与 Android 常见使用问题 |
| `public-knowledge-curator` | 将资料整理为适合公开发布的知识内容 |
| `github-repo-maintainer` | 检查仓库结构、目录说明和索引 |

技能文件位于仓库根目录的 `.agents/skills/` 中。

## 技能选择与协作

- 学习课程、视频和知识地图：使用 `course-knowledge-organizer`。
- 调查 AI 产品、版本、价格、地区限制和安装问题：使用 `ai-tool-researcher`。
- Windows 或 Android 操作指导：使用 `windows-android-helper`。
- 整理可公开发布的资料：使用 `public-knowledge-curator`。
- 检查仓库结构、README、文件和链接：使用 `github-repo-maintainer`。
- 一个任务需要多个技能时，先完成研究或整理，再进行归档和仓库维护；每一步都要检查结果。
- 技能只提供工作流程，不自动获得外部账户、电脑或仓库权限。

## 成熟技能推荐

请先阅读 [成熟技能推荐与安装指南](./成熟技能推荐与安装指南.md)。优先选择 OpenAI 官方维护的 Codex 技能，并按实际需要安装，不追求数量。

## 使用方法

1. 在 Codex 中打开 NO1 仓库。
2. 等待 Codex 识别仓库技能；如未显示，重新打开项目或重启 Codex。
3. 在提示中输入技能名，例如 `$course-knowledge-organizer`，或直接描述相符任务让 Codex 自动判断。
4. 完成后检查结果，再提交或同步到 GitHub。

## 安全规则

- NO1 是公开仓库，只能保存公开资料和通用方法。
- 不放密码、验证码、API 密钥、个人身份信息、公司机密或私人记录。
- 外部技能先检查来源、许可证、脚本和网络行为，再决定是否安装。
- 用户要求分析或整理，不自动代表授权写入 GitHub；只有明确要求保存、归档、提交或更新时才写入。
- 未经明确授权，不删除原始文件、不改变仓库可见性、不把 NO2 内容复制到 NO1。
- 公开资料来源或授权不清楚时，先询问；不能可靠脱敏的资料不得发布。
