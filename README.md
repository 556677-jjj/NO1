# NO1｜个人资料中心

这是一个用于整理个人数字资料、学习内容和实用工具的**公开知识库**。请只放适合公开分享、且已检查隐私与版权的内容。

## 分类目录

1. [AI 工具](01-AI工具/README.md)：ChatGPT、Gemini、Claude、Codex 等 AI 工具的使用记录。
2. [电脑软件](02-电脑软件/README.md)：Windows 软件、安装配置、使用技巧和故障处理记录。
3. [手机应用](03-手机应用/README.md)：手机应用介绍、安装配置和使用经验。
4. [学习资料](04-学习资料/README.md)：教程、课程笔记、知识总结和学习计划。
5. [个人生活](05-个人生活/README.md)：日常计划、生活清单和个人事务管理资料。
6. [GitHub 优秀项目收藏](06-GitHub优秀项目收藏/README.md)：发现、筛选和记录 GitHub 上值得尝试的开源项目与实用程序。

## 使用约定

- 每个分类使用独立文件夹，内容逐步补充。
- 新增资料时尽量写清标题、日期、用途和来源。
- 重要内容优先使用 Markdown（.md）文档，便于阅读和搜索。
- 未经确认，不删除或覆盖已有资料。
- 不要保存密码、验证码、银行卡号、身份证号码等敏感信息。

## 后续扩展

如果以后出现新的主题，可以新增分类目录，并在本页更新目录索引。


## 与私人仓库 NO2 的分工

- 本仓库 NO1 为 **Public（公开）**：存放可公开分享的 AI 学习、电脑软件、手机应用、教程和通用经验。
- [NO2](https://github.com/556677-jjj/NO2) 为 **Private（私有）**：存放个人工作、私人资料、生活记录和未公开项目。
- 不要把密码、验证码、API 密钥、身份证号码、私人联系方式、公司机密或未经授权的他人资料放入本仓库。
- 从 NO2 分享到 NO1 时，必须先得到明确要求，再制作脱敏副本并检查内容、图片、附件和来源；不直接搬运私人原件。

## 个人知识管理协作流程

1. **收集**：把资料、问题、截图或链接交给 ChatGPT，并说明用途（如不清楚，可先由 ChatGPT 帮忙判断）。
2. **判断归属**：公开通用知识归 NO1；个人工作、生活和未公开内容归 NO2；不确定时先放 NO2 的「06-临时收集」。
3. **整理**：提炼标题、摘要、步骤、案例、来源、日期和关键词；尽量使用通俗中文。
4. **核验**：事实、软件版本、价格、地区限制和操作步骤等易变化内容，标注核对日期与来源；未验证的内容明确标记。
5. **归档**：写入正确仓库和分类，更新相关索引；重要文件不擅自覆盖或删除。
6. **交付**：提供仓库文件链接，并说明新增或修改了什么。

更多操作规则见 NO2 的「个人知识管理协作规则」。
